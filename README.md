# Ziggurat

A total rebalance of Age of Wonders (1999).

**[Read the manual](https://bing-xi.github.io/Ziggurat-Engine-Mod/)** - units, abilities,
spells, structures and rules, with the vanilla value beside each change.

## Install

Download the installer from [Releases](../../releases) and run it. It needs an existing
Age of Wonders installation; point it at that folder.

Ziggurat installs into a `Ziggurat\` subfolder and reads its own registry key, so **your
vanilla game is not modified** - both stay playable side by side:

- `AoW.exe` - vanilla
- `Ziggurat\AoWz.exe` - Ziggurat
- `Ziggurat\AoWzEd.exe` - the map editor, Ziggurat-oriented

To uninstall, delete the `Ziggurat\` folder.
